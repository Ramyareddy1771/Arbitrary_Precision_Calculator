#🚀 **Project Showcase: Arbitrary Precision Calculator (APC) using C**

I'm excited to share my **Arbitrary Precision Calculator (APC)** project, developed using the C programming language! 💻
🔹 **Project Overview:**
This project is to design and implement an APC that can perform arithmetic operations on large numbers (such as addition, subtraction, multiplication &amp; division) that exceed the limits of standard data types. The calculator will use double linked lists to represent &amp; manipulate these large numbers, allowing for precise calculations.

🔹 **Key Features:**
✅ Addition (+)
✅ Subtraction (-)
✅ Multiplication (×)
✅ Division (/)
✅ Linked-list-based number representation
✅ Command-line interface for user interaction

🔹 **Technical Skills:**
• C Programming
• Data Structures and Algorithms
• Linked Lists
• Pointers and Dynamic Memory Allocation
• Command-Line Argument Handling
• Arithmetic Logic Implementation

🎯 **Key Learning:**
This project strengthened my understanding of linked lists, dynamic memory management, and implementing arithmetic operations in C.

I'm looking forward to applying these skills to more challenging software development projects!
